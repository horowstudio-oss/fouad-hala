# Fouad & Hala — Wedding Invitation

دعوة زفاف إلكترونية ثابتة جاهزة لـ GitHub Pages.

## التعديل السريع
افتح `config.js` فقط وعدّل الأسماء، التاريخ، الوقت، القاعة، المدينة والنصوص.

## الموسيقى
ضع ملف الموسيقى باسم `music.mp3` داخل مجلد `assets/`.
> المتصفحات تمنع التشغيل التلقائي بصوت؛ لذلك تبدأ الموسيقى عند أول لمسة/نقرة من الزائر، ويوجد زر صوت صغير فقط للتحكم بالموسيقى.

## النشر على GitHub Pages
1. ارفع محتويات المجلد إلى Repository باسم `fouad-hala`.
2. من Settings > Pages اختر Deploy from a branch.
3. اختر `main` و `/root` ثم Save.

## الملفات
- `index.html` الهيكل
- `styles.css` التصميم والحركات
- `script.js` الأنيميشن والعداد والموسيقى
- `config.js` كل معلومات الدعوة في مكان واحد
- `assets/music.mp3` الموسيقى (أضف الملف الذي سترسله)
